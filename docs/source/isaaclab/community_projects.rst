Community Projects
==================

This list includes only community projects based on Isaac Lab 3.0 or later.
Follow each project's documentation for its supported versions and setup.

* `allegro-inhand-rolling <https://github.com/beyondlm/allegro-inhand-rolling>`_:
  Allegro hand cylinder rolling with cached grasps and a pretrained policy.
* `basic-locomotion-isaaclab <https://github.com/iit-DLSLab/basic-locomotion-isaaclab>`_:
  Quadruped locomotion with sim-to-sim and sim-to-real transfer.
* `robot_lab <https://github.com/fan-ziqi/robot_lab>`_:
  Locomotion tasks for quadrupeds, wheeled-legged robots, and humanoids.

To add your project, open a pull request updating this page and the README with a repository link
and a short description. Your repository should document its Isaac Lab 3.0+ compatibility.
