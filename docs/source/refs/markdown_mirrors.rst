Markdown documentation
======================

The primary installation, quickstart, tutorial, editor setup, and troubleshooting
pages are also available as plain Markdown for agents and other tools.
Open the `Markdown index <../../../markdown.md>`__ to find these mirrors, or use
**Download this page as Markdown** at the top of a supported HTML page.

Mirrors are generated from the same resolved content as the HTML pages during
each documentation build. They include expanded code snippets, included files,
version pins, and the content of every platform tab and dropdown. Links between
mirrored pages point to Markdown; other links point to the HTML documentation.
Use the mirrors from the same documentation version as your checkout.

To generate mirrors locally, follow the documentation build instructions in
``docs/README.md``. The index is written to ``docs/_build/current/markdown.md``;
each mirror is written beside its corresponding HTML page.
