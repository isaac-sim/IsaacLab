* Added reusable non-learning scene helpers for the Rizon-Sharpa coffee IK demo
  with coupled Newton MPM/MJWarp, procedural tableware, absolute palm and finger
  controls and per-world resets. The licensed robot bundle remains external.
* Added a single-scoop scripted IK controller and Apple Vision Pro retargeting,
  named grasp-reset authoring and experimental
  contact grasping. The default uses a measured-palm mounted spoon.
* Added mass-preserving soluble-coffee conversion during captured physics,
  liquid pressure profiles resolved after configuration overrides, and optional
  conservative colour transport with temporally filtered surface reconstruction.
* Added optional GL, RTX and Kit presentation, passive visual grains, a public
  NVIDIA kitchen backdrop without physics, smooth camera framing and streamed
  simulation-time MP4 recording with resolved settings, dose metrics and
  independently measured colour-tracer mass.
  The demo uses a 4 mm grid. Presentation is optional, and spoon margins taper
  to zero at the rim. The README describes reusing the scene in a future RL task.
