# Isaac Lab Fovi

Foveated camera sensors for Isaac Lab: retina-like images, dense where a movable gaze points and sparse in the
periphery, built on the [fovi](https://pypi.org/project/fovi/) library, with manager terms for active gaze.

Install with the `fovi` extra (`uv sync --extra fovi`) and try `isaaclab demo foveated-camera`. See the
[Foveated Camera](https://isaac-sim.github.io/IsaacLab/main/source/concepts/sensors/foveated_camera.html) page of the
Isaac Lab documentation.
