* Changed the Newton visualizer HUD. An always-visible header shows the task and run, physics backend, environment
  count, step and simulation time, simulation rate, and a paused badge. Below it are the **Playback**, **Camera View**
  (grouped under **Camera Source**, **Rendering**, **Camera Settings**, **Camera Data**, and a **Window** group that
  holds the VSync checkbox), **Scene** (visible envs, visualization markers, visual overlays), and **Control Bindings**
  sections, with tooltips throughout. The window and HUD are now named "Newton Visualizer", Newton's Selection API
  panel is the "Articulation Selection", and the Focal Length slider is limited to 5-64 mm. The Window FPS slider and
  the RTX Background selector were removed.
* Changed the performance and model statistics overlay of the Newton visualizer to start closed, behind a "Stats"
  button.
* Added tooltips to each visualization marker group and to each live plot.
