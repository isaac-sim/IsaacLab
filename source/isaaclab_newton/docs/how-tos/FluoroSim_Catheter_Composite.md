# Catheter Composite on the FluoroSim API

## Overview

The fluoroscopy simulation pipeline composites a physics-simulated catheter/guidewire onto Digitally Reconstructed Radiograph (DRR) backgrounds using **Beer-Lambert transmission attenuation**. The catheter darkens the X-ray image based on material attenuation coefficients and projected cylindrical thickness — matching real fluoroscopy appearance.

Two visualisation frontends exist:

| Frontend | File | Rendering |
|----------|------|-----------|
| **OpenCV + Beer-Lambert** | `visualize_rod_fluoroscopy.py` | 2D compositing via Beer-Lambert; real-time OpenCV window |
| **Isaac Lab + DRR backdrop** | `visualize_rod_fluoro_isaaclab.py` | 3D capsule markers over a textured DRR quad in Omniverse |

This document describes the OpenCV Beer-Lambert pipeline, which produces output like the frame below.

### Example Output

![Fluoroscopy frame — AP view, Beer-Lambert compositing](fluoro_frames/fluoro_frame_0022.png)

- **Background**: DRR of a skull in AP view (generated by DiffDRR+Slang from CT data)
- **Catheter**: Dark line entering from the cervical spine region, composited via Beer-Lambert attenuation

## Pipeline: Solver State to Fluoroscopy Frame

```text
RodSolver.step(dt)
    → solver.data.positions  (torch tensor, metres)
        → × 1000 → pos_3d (mm)
            → project_points_3d_to_2d(pos_3d, K, Rt)  → uv (pixels)
            → compute_projected_radii(pos_3d, K, Rt, r) → radii_px
                → composite_catheter_beer_lambert(DRR, uv, radii_px, mu_profile)
                    → exp(-Σ mu·chord) attenuation
                    → + scatter + PSF + Poisson noise
                        → final fluoroscopy frame
```

---

## Stage 1 — Solver Provides Catheter State

Three solver backends expose the same key tensor: **3D centerline positions**.

| Solver | State Access | Shape |
|--------|-------------|-------|
| `RodSolver` | `solver.data.positions[0]` | `(num_segments, 3)` in metres |
| `XPBDRodSolver` | `solver.positions` | `(num_points, 3)` in metres |
| `NewtonXPBDRodSolver` | `solver.positions` | `(1, num_segments, 3)` in metres |

Each simulation tick calls `solver.step(dt)`, then positions are extracted and scaled from **metres → millimetres** (`× 1000`):

```python
if use_xpbd:
    pos_3d = solver.positions.cpu().numpy() * SCALE   # SCALE = 1000
else:
    pos_3d = solver.data.positions[0].cpu().numpy() * SCALE
```

Orientations from the solver are **not used** by the Beer-Lambert pipeline — only centerline positions and segment radii drive the image.

---

## Stage 2 — C-Arm Projection (3D → 2D)

The pipeline models a real fluoroscope with standard pinhole camera matrices.

### Intrinsics — `make_carm_intrinsics(sid, pixel_spacing, image_size)`

Builds a 3×3 intrinsic matrix `K`:

```text
        [ f   0   cx ]
    K = [ 0   f   cy ]       f = SID / pixel_spacing
        [ 0   0   1  ]
```

Default parameters: SID = 1000 mm, pixel spacing = 0.81 mm/px, image = 512×512.

### Extrinsics — `make_carm_extrinsics(sod, carm_angle_deg, cran_caud_deg)`

Builds a 3×4 `[R | t]` matrix for the C-arm gantry:

- **Iso-centre** at world origin
- **At 0°/0°** the X-ray source is at `(0, 0, −SOD)` looking +Z
- **LAO/RAO** rotates around the patient Y-axis
- **CRAN/CAUD** rotates around the X-axis
- Rotation: `R = Rx(cran_caud) @ Ry(lao_rao)`

### Projection — `project_points_3d_to_2d(points_3d, K, Rt)`

Standard pinhole projection: `P = K @ Rt`, producing `(N, 2)` pixel coordinates `uv`.

## Stage 3 — Per-Segment Attenuation Profile

`_segment_attenuation_profile(num_segments)` assigns a linear attenuation coefficient (`mu × nominal diameter`) to each segment, modelling a realistic catheter construction:

| Region | % of length | Material | mu value |
|--------|------------|----------|----------|
| Proximal marker band | First 2 segments | Tungsten | 3.0 |
| Braided shaft | 0–60% | Nitinol | 0.8 |
| Transition zone | 60–85% | Sparse braid + polymer | 0.8 → 0.2 |
| Soft polymer tip | 85–95% | Polymer | 0.15 |
| Distal tip marker | Last 3 segments | Platinum coil | 5.0 |

Higher `mu` values produce darker (more radiopaque) segments on the fluoroscopy image. The distal platinum marker appears darkest; the polymer tip is nearly invisible.

---

## Stage 4 — Beer-Lambert Compositing

`composite_catheter_beer_lambert()` is the core rendering function. It operates in four sub-stages:

### 4a. Attenuation Map Construction

For each segment, the function computes the projected cylinder chord thickness at every pixel within the segment's bounding box:

```text
    t(d) = 2 × sqrt(r² − d²)      for d < r
```

where `d` is the perpendicular distance from the pixel to the segment centerline and `r` is the projected pixel radius. The normalised chord is weighted by `mu` and **accumulated additively** into an attenuation map:

```text
    atten_map[v, u] += mu_i × chord_norm_i(u, v)
```

This additive accumulation means self-crossings produce correctly increased opacity.

### 4b. Beer-Lambert Transmission

The DRR background is darkened multiplicatively:

```text
    I_final(u,v) = I_DRR(u,v) × exp(−atten_map(u,v))
```

This produces:
- Physically correct smooth-edged darkening
- Background anatomy visible through the catheter
- Additive opacity at self-crossings

### 4c. Veiling Glare / Scatter

A fraction of the blocked intensity is re-added as a large-kernel Gaussian blur, simulating X-ray scatter:

```text
    blocked = I_DRR × (1 − transmission)
    scatter = GaussianBlur(blocked, σ=18px)
    I_final += 0.03 × scatter
```

### 4d. Detector Effects

- **PSF blur** — small Gaussian blur (`σ = 0.7 px`) models the detector point-spread function
- **Poisson noise** — quantum noise at 2000 photons/pixel mean count:

```text
    photons = I × photon_count
    noisy = Poisson(photons) / photon_count
```

---

## Stage 5 — Cone-Beam Magnification

`compute_projected_radii()` accounts for cone-beam geometry. Segments closer to the X-ray source appear larger on the detector:

```text
    radius_px = physical_radius_mm × f_px / z_cam
```

where `z_cam` is the segment midpoint depth in camera coordinates and `f_px` is the focal length in pixels. Radii are clamped to `[1, 50]` pixels.

---

## Stage 6 — HUD Overlay

`draw_hud()` renders green telemetry text onto the frame:

- `SIM` — simulation wall-clock time
- `FPS` — rendering frame rate
- `TIP` — distal tip position in mm `(x, y, z)`
- `C-ARM` — current gantry angle in degrees
- View label (AP, LAO 30, Lateral, RAO 30) in the top-right corner

### Why the Frames Appear Similar

1. **The catheter is tiny relative to the DRR.** The rod is only ~120 mm long with a 1 mm radius, projected onto a 512x512 image covering a ~250 mm field-of-view. It appears as a thin dark line that is difficult to distinguish against the dense skull anatomy.

2. **No external forces beyond gravity.** The rod simply drops under gravity from its initial position and reaches a static equilibrium. After ~30s of simulation time the tip stops moving entirely (frames 899 and 1799 are identical).

3. **The DRR background dominates the image.** The skull anatomy is the same static DRR in every frame. The Beer-Lambert compositing produces subtle darkening rather than a bright opaque overlay — by design this matches how a real catheter appears under fluoroscopy (thin, semi-transparent).

4. **Poisson noise varies frame-to-frame.** The quantum noise is re-sampled each frame with a fresh random seed, producing slight per-pixel variation even when the catheter geometry is identical. This is the only visual difference between the late equilibrium frames.

### Snapshot Save Logic

Frames are saved at four specific points during each simulation run (see `run_fluoroscopy_overlay()`):

```python
if frame_count in (0, total_frames // 4, total_frames // 2, total_frames - 1):
    snap_path = f"/tmp/fluoro_frame_{frame_count:04d}.png"
    cv2.imwrite(snap_path, canvas)
```

The 14 frames in the `fluoro_frames/` directory come from **multiple runs** with different `--duration` settings, each saving its own set of four snapshots.
